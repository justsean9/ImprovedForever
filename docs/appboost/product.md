# Product

**Improved Forever - Controller & Gamepad** is a free set of World of Warcraft addons for **WoW Forever** (the `_forever_` client) that make playing with a controller better. It works with Xbox, PlayStation (DualSense) and Switch Pro controllers. Everything is set up and used from the controller. Every module except Controller and Wheel also works with mouse and keyboard.

- Author: MarkG (GitHub `markgravity`). The user builds it, so posts must say "I built this".
- Structure: a required core (`ImprovedForever`) plus optional modules, each its own addon: Wheel, Vibration, Minimap, Map, Chat, Auction, Junk, Wiki, Journal, Fishing, Camp, Immersion, QuestTracker.
- Install: CurseForge app (search "Improved Forever"), or manual zips from GitHub Releases into `World of Warcraft/_forever_/Interface/AddOns/`.
- Price: free ("free and always will be"). Optional tips via Ko-fi and PayPal.
- Links: https://www.curseforge.com/wow/addons/improved-forever, https://github.com/markgravity/ImprovedForever
